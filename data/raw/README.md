# Dados brutos

Coloque aqui o arquivo `amazon.csv`, baixado de:
<https://www.kaggle.com/datasets/karkavelrajaj/amazon-sales-dataset>

O arquivo não é versionado (ver `.gitignore`). Confira a licença na página do dataset antes de redistribuí-lo.
Características: 1.465 linhas, 16 colunas, preços em rupias indianas (₹).

Para atualizar o dashboard, aponte o parâmetro `CaminhoCSV` do Power Query para este arquivo (Transformar dados → Gerenciar parâmetros).
